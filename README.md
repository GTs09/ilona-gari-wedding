# ილონა და გარი — საქორწილო მოწვევა

მობილურზე მორგებული ერთგვერდიანი საქორწილო მოწვევა, შექმნილი თქვენი PDF მოწვევის პირველი და მეორე გვერდის ვიზუალური სტილის მიხედვით.

## GitHub Pages-ზე ატვირთვა

1. შექმენი ახალი GitHub repository.
2. ატვირთე ამ საქაღალდის ყველა ფაილი ისე, რომ `index.html` იყოს repository-ის მთავარ დონეზე.
3. GitHub-ში შედი: **Settings → Pages**.
4. Source-ში აირჩიე **Deploy from a branch**.
5. აირჩიე `main` branch და `/ (root)`.
6. შეინახე და რამდენიმე წუთში მიიღებ საჯარო ბმულს.
